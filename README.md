## Verify the installer before running it

Bitvise says its installers are cryptographically signed. Before launching the installer, verify in Windows File Explorer that its digital signature is present and Windows reports **“This digital signature is OK.”** See Bitvise's [official signature verification instructions](https://www.bitvise.com/verify-installer-signature). Do not run a Bitvise installer that lacks a valid Bitvise digital signature.
